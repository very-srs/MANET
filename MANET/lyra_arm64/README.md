# Lyra codec artifacts (aarch64)

Two files belong here, and every tarball builder installs them:

- `libgstlyra.so` — GStreamer plugin providing `lyraenc`, `lyradec`,
  `rtplyrapay`, `rtplyradepay`
- `model_coeffs/` — Lyra v2 model weights

They are **not** generated by any build in this repository automatically — see
"Lyra codec plugin" in `MANET/packaging/README.md` for the two-stage build.

Until they are present, every builder warns and the resulting tarball ships
without the codec. Nodes then fall back to opus, which on a mesh configured for
lyra (the default) means they cannot hear or be heard.
